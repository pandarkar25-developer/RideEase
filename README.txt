# RideEase Website

A responsive bike and car rental website concept based on the supplied RideEase poster.

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, vehicle filters, date validation, and booking UI interactions

## Run locally
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Open `index.html` in your browser.

Vehicle photos are loaded from Unsplash, so an internet connection is required for those images. Prices, business details, and booking interactions are demo content. Connect a real booking backend and replace demo contact details before publishing.
